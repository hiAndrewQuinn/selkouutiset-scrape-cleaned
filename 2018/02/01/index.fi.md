# Torstai 1.2.2018 (tv)

Presidentti Niinistön uusi virkakausi alkoi. Lumisade vaikeutti liikennettä. Automaattivaihteen suosio kasvaa. Hotelleja rakennetaan entistä enemmän. Säätiedot.
