# Maanantai 16.10.2017 (tv)

Joukko yliopistoja aloittaa yhteistyön, koska teollisuus tarvitsee lisää insinöörejä. Helsingin Kätilöpisto suljetaan tällä viikolla. Itävallan vaaleissa menestyivät hyvin puolueet, jotka vastustavat maahanmuuttoa ja islamia. Suomalainen Mikko Martikainen näyttää kiinalaisille, miten lunta varastoidaan. Säätiedot.
