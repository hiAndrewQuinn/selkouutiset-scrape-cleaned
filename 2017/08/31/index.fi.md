# Torstai 31.8.2017 (tv)

Pankit haluavat taloista kuntotarkastuksen, ennen kuin asiakas saa taloa vastaan lainaa. Prinsessa Dianan kuolemasta on 20 vuotta. Singaporen Suomi-koulu onnittelee 100-vuotiasta Suomea. Sää.
