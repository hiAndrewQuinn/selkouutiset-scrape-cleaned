# Sunnuntai 11.8.2019 (radio)

Poliisi tutkii parturi-kampaamoja, jotka käyttävät hyväksi ulkomaalaisia työntekijöitä. Suomen uuden hallituksen ensimmäinen budjetti valmistuu tänä syksynä. Muslimien Id al-Adha -juhla on alkanut. Nuori painija Said-Magomed Tasukhanov on kuollut.

## Paperittomia käytetään hyväksi

![Parturin pesupenkkejä.](https://img.img-cdn.yle.fi/crop_fill,w_767,h_431,dpr_1/f_auto/13-3-6889674)

Avaa kuvien katselu

Paperiton työntekijä saa usein liian pientä palkkaa. Kuva: Elina Kinos / Yle

Aluksi asiaa ulkomaalaisista työntekijöistä.

Poliisi tutkii monia parturi-kampaamoja, jotka käyttävät hyväksi ulkomaalaisia työntekijöitä. Hyväksikäyttö voi tarkoittaa esimerkiksi sitä, että työntekijä saa liian pientä palkkaa.

Usein hyväksikäytön uhri on paperiton, eli hänellä ei ole lupaa olla Suomessa. Paperiton ei usein uskalla itse ilmoittaa hyväksikäytöstä poliisille.

Paperittomia käytetään hyväksi myös muilla aloilla kuin parturiliikkeissä. Esimerkiksi ravintoloissa ja rakennusalalla työskentelee paperittomia, jotka saavat tosi pientä palkkaa.

Tiedot ovat Ylen MOT-ohjelmasta, ja asiasta voi lukea lisää Ylen nettisivuilla. Osoite on yle.fi.

## Budjettia valmistellaan

![Antti Rinne](https://img.img-cdn.yle.fi/crop_fill,w_767,h_431,dpr_1/f_auto/13-3-10911697)

Avaa kuvien katselu

Pääministeri Antti Rinteen hallitus tekee budjetin ensimmäistä kertaa. Kuva: Markku Ulander / Lehtikuva

Suomen uuden hallituksen ensimmäinen budjetti valmistuu tänä syksynä. Budjetti kertoo, mihin valtio käyttää rahaa ensi vuonna.

Budjettiehdotus valmistuu ensi viikolla. Sen jälkeen hallitus vielä neuvottelee ehdotuksesta, ennen kuin budjetti on valmis.

Asiantuntijoiden mielestä budjetin tärkein asia on, miten Suomeen saadaan uusia työpaikkoja. Tehtävä on asiantuntijoiden mielestä vaikea, koska talouskasvu hidastuu.

## Muslimien juhla alkoi

![Id al-Adha -juhlaa Itäkeskuksessa viettävä perhe.](https://img.img-cdn.yle.fi/crop_fill,w_767,h_431,dpr_1/f_auto/13-3-10917870)

Avaa kuvien katselu

Myös Suomen muslimit viettävät Id al-Adha -juhlaa. Kuva: Tanja Heino / Yle

Muslimien Id al-Adha -juhla on alkanut. Juhla liittyy pyhiinvaellukseen eli hajjiin Saudi-Arabian Mekassa.

Id al-Adha -juhlaa vietetään myös muualla. Myös Suomen muslimit viettävät Id al-Adhaa.

Id al-Adha kestää monta päivää. Juhlan aikana esimerkiksi teurastetaan eläimiä.

Monet muslimit viettävät Id al-Adhaa perheen parissa. Hyvä ruoka ja lahjat lapsille kuuluvat juhlaan.

## Nuori painija kuoli

![Said-Magomed Tasukhanov.](https://img.img-cdn.yle.fi/crop_fill,w_767,h_431,dpr_1/f_auto/13-3-10917771)

Avaa kuvien katselu

Said-Magomed Tasukhanov kuoli lauantaina. Kuva: Helsingin Paini-Miehet r.y.

Lopuksi suru-uutinen urheilumaailmasta: Nuori painija Said-Magomed Tasukhanov on kuollut.

18-vuotias Tasukhanov kuoli auto-onnettomuuden jälkeen.

Onnettomuus tapahtui Virossa, kun Tasukhanov oli palaamassa Suomeen. Hän harjoitteli kesällä Venäjällä.

Tasukhanov oli 5 kertaa Suomen mestari nuorten sarjoissa. Keväällä hän sai ensimmäisen SM-mitalin aikuisten sarjassa.

Tasukhanov sai Suomen kansalaisuuden 2 kuukautta sitten.
