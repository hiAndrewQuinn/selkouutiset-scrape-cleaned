# Keskiviikko 6.9.2017 (tv)

Suomalainen koulutus on vientituote. Helsingissä vietettiin uusien Suomen kansalaisten juhlaa. Kaupan alalla on hyvä maine. Puoli miljoonaa suomalaista kärsii tuoksuista. Sää.
