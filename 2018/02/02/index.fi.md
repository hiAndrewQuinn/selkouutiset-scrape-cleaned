# Perjantai 2.2.2018 (tv)

Helsingissä oli iso mielenosoitus työttömyysturvan aktiivimallia vastaan. Aktiivimallin takia perjantaina oli myös lakkoja. Taitelija Kari Vehosalo on saanut Ars Fennica -palkinnon. Suomesta lähtee Etelä-Korean olympialaisiin 102 urheilijaa. Säätiedot.
